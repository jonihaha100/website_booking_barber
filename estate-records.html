🏛️ Panduan Sinkronisasi Database Google Sheets

Website Greenwood terintegrasi dengan Google Sheets dan Google Calendar untuk mencatat data reservasi tamu dari berbagai perangkat (HP/Laptop tamu).

⚡ 4 Langkah Mudah Mengaktifkan Sync:
  1. Buka script.google.com dan buka proyek Greenwood Sync.
  2. Salin seluruh kode terbaru dari file google-calendar-sync.gs ke editor.
  3. Pilih fungsi testRunDirectly di menu atas lalu klik Jalankan (Run) untuk memberikan izin Google Drive, Sheets, dan Calendar.
  4. Klik tombol Deploy → Manage Deployments → Edit (pensil) → Version: New Version → Deploy.

💡 Setelah deployment diperbarui, tekan tombol "Sinkronkan Cloud" untuk memuat seluruh reservasi tamu ke layar admin ini secara instan.
